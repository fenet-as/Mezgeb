# Mezgeb — User Stories

## 1. Purpose

This document describes the primary user interactions with Mezgeb from the user's perspective.

User stories follow the format:

> **As a [user], I want to [action], so that [reason].**

The stories are grouped by the major areas of the application.

---

# 2. Authentication

### US-AUTH-01 — Register

As a new user, I want to create an account so that I can keep my learning data private and persistent.

### US-AUTH-02 — Login

As a registered user, I want to log in so that I can access my learning data.

### US-AUTH-03 — Logout

As a logged-in user, I want to log out so that my account remains protected on shared devices.

### US-AUTH-04 — Profile

As a user, I want to view and update my profile so that my account information remains current.

---

# 3. Dashboard

### US-DASH-01 — View Overview

As a learner, I want to see an overview of my current learning activity so that I can quickly understand what I am working on.

### US-DASH-02 — View Active Goals

As a learner, I want to see my active learning goals so that I can quickly return to what I am currently studying.

### US-DASH-03 — View Recent Activity

As a learner, I want to see my recent learning activity so that I can remember what I have been doing.

### US-DASH-04 — View Study Time

As a learner, I want to see my recent study time so that I can understand how much time I have been investing in learning.

### US-DASH-05 — View Progress

As a learner, I want to see my goal progress from the dashboard so that I can quickly understand how far I have progressed.

### US-DASH-06 — Empty Dashboard

As a new user, I want the dashboard to explain what I can do when I have no learning data so that I know how to get started.

---

# 4. Learning Goals

### US-GOAL-01 — Create Goal

As a learner, I want to create a learning goal so that I can define what I want to learn.

### US-GOAL-02 — Describe Goal

As a learner, I want to add a description to my goal so that I can define what I want to accomplish.

### US-GOAL-03 — Set Dates

As a learner, I want to set a start date and target date so that I can give my learning goal a timeframe.

### US-GOAL-04 — View Goals

As a learner, I want to see all my learning goals so that I can manage my different areas of study.

### US-GOAL-05 — View Goal Details

As a learner, I want to open a goal and see its milestones, tasks, sessions, and progress so that I can understand the complete state of that goal.

### US-GOAL-06 — Edit Goal

As a learner, I want to edit my goal information so that I can update it when my plans change.

### US-GOAL-07 — Archive Goal

As a learner, I want to archive a goal so that completed or inactive goals do not clutter my active learning space.

### US-GOAL-08 — Delete Goal

As a learner, I want to delete a goal so that I can remove information I no longer need.

### US-GOAL-09 — Track Goal Progress

As a learner, I want to see the progress of a goal so that I can understand how much of it I have completed.

---

# 5. Milestones

### US-MILE-01 — Create Milestone

As a learner, I want to divide a large learning goal into milestones so that the goal feels easier to manage.

### US-MILE-02 — Edit Milestone

As a learner, I want to edit a milestone so that I can adjust my learning plan.

### US-MILE-03 — Delete Milestone

As a learner, I want to delete a milestone so that I can remove stages that are no longer relevant.

### US-MILE-04 — Reorder Milestones

As a learner, I want to reorder milestones so that they reflect the order in which I intend to learn.

### US-MILE-05 — Track Milestone Progress

As a learner, I want to see milestone progress so that I know which stages of my goal are complete.

---

# 6. Tasks

### US-TASK-01 — Create Task

As a learner, I want to create a task within a milestone so that I can define a specific learning action.

### US-TASK-02 — Complete Task

As a learner, I want to mark a task as completed so that my progress is updated.

### US-TASK-03 — Reopen Task

As a learner, I want to reopen a completed task so that I can correct my progress if necessary.

### US-TASK-04 — Edit Task

As a learner, I want to edit a task so that I can correct or update it.

### US-TASK-05 — Delete Task

As a learner, I want to delete a task so that outdated tasks do not remain in my learning plan.

### US-TASK-06 — Track Task Status

As a learner, I want to see whether a task is not started, in progress, or completed so that I understand its current state.

---

# 7. Learning Sessions

### US-SESSION-01 — Record Session

As a learner, I want to record a learning session so that my study activity is documented.

### US-SESSION-02 — Record Duration

As a learner, I want to record how long I studied so that I can track my total learning time.

### US-SESSION-03 — Associate Session

As a learner, I want to associate a session with a goal or milestone so that my study history has context.

### US-SESSION-04 — Describe Session

As a learner, I want to describe what I studied during a session so that I can remember what I worked on.

### US-SESSION-05 — Edit Session

As a learner, I want to edit a session so that I can correct inaccurate information.

### US-SESSION-06 — Delete Session

As a learner, I want to delete a session so that incorrect or unwanted records can be removed.

### US-SESSION-07 — Review Sessions

As a learner, I want to review previous learning sessions so that I can understand my study history.

---

# 8. Learning Journal

### US-JOURNAL-01 — Create Entry

As a learner, I want to write a journal entry so that I can record what I learned and experienced.

### US-JOURNAL-02 — Reflect

As a learner, I want to write reflections about difficult concepts, discoveries, and mistakes so that I can learn from my experience.

### US-JOURNAL-03 — Associate Entry

As a learner, I want to associate a journal entry with a goal or milestone so that the reflection has context.

### US-JOURNAL-04 — Edit Entry

As a learner, I want to edit a journal entry so that I can improve or correct it later.

### US-JOURNAL-05 — Delete Entry

As a learner, I want to delete a journal entry so that I can remove information I no longer want.

### US-JOURNAL-06 — Browse Journal

As a learner, I want to browse previous entries so that I can look back at my learning journey.

---

# 9. Progress

### US-PROGRESS-01 — View Goal Progress

As a learner, I want to see how much of each goal I have completed so that I can understand my progress.

### US-PROGRESS-02 — View Study Time

As a learner, I want to see my accumulated study time so that I can understand my learning effort.

### US-PROGRESS-03 — View Activity

As a learner, I want to see my learning activity over time so that I can identify patterns in my study habits.

### US-PROGRESS-04 — View Streak

As a learner, I want to see my current learning streak so that I can keep track of consistent study activity.

### US-PROGRESS-05 — Review Historical Progress

As a learner, I want to review previous learning activity so that I can see how my learning has developed over time.

---

# 10. Navigation

### US-NAV-01 — Navigate Application

As a user, I want clear navigation between the main areas of Mezgeb so that I can quickly find what I need.

### US-NAV-02 — Return to Dashboard

As a user, I want to return to the dashboard from anywhere in the application so that I can quickly access my overview.

### US-NAV-03 — Navigate to Goal

As a user, I want to navigate directly to a goal so that I can continue working on it.

---

# 11. Error and Empty States

### US-STATE-01 — Empty Goals

As a new learner, I want to see helpful guidance when I have no goals so that I know how to create my first one.

### US-STATE-02 — Empty Journal

As a learner, I want to see useful guidance when I have no journal entries so that I understand how to start documenting my learning.

### US-STATE-03 — Loading

As a user, I want the application to show that content is loading so that I know the application is working.

### US-STATE-04 — Error

As a user, I want to understand when something goes wrong so that I know what happened and what I can do next.

### US-STATE-05 — Failed Save

As a user, I want to know when an action fails to save so that I do not assume my data was stored successfully.

---

# 12. Accessibility

### US-A11Y-01 — Keyboard Navigation

As a keyboard user, I want to navigate the application without a mouse so that I can use Mezgeb effectively.

### US-A11Y-02 — Accessible Forms

As a user, I want form controls to have clear labels and error messages so that I understand what information is required.

### US-A11Y-03 — Accessible Feedback

As a user, I want important status changes to be communicated accessibly so that I do not miss important information.

---

# 13. Future User Stories

The following stories are intentionally deferred until after the MVP.

### AI

* As a learner, I want AI to summarize my journal entries so that I can review my learning more quickly.
* As a learner, I want AI to help break a large goal into milestones so that I can create a learning plan more easily.
* As a learner, I want AI to identify patterns in my learning history so that I can understand my habits.

### Search

* As a learner, I want to search my journal so that I can quickly find previous reflections.
* As a learner, I want to filter my learning activity so that I can focus on a particular goal or period.

### Integrations

* As a learner, I want to connect my calendar so that I can coordinate learning sessions with my schedule.
* As a learner, I want to export my learning history so that I can keep a copy of my data.

These stories should not influence the MVP architecture unless they introduce requirements that need to be considered early.

---

# 14. Core User Journey

The primary user journey is:

```text
Register
   ↓
Create Learning Goal
   ↓
Create Milestones
   ↓
Create Tasks
   ↓
Study
   ↓
Record Learning Session
   ↓
Complete Tasks
   ↓
Write Reflection
   ↓
Review Progress
   ↓
Continue Learning
```

This journey represents the central purpose of Mezgeb.

---

# 15. Story Priorities

User stories will be prioritized as:

```text
P0 — Required for MVP
P1 — Important after MVP
P2 — Future
```

The core P0 journey is:

```text
Authentication
    ↓
Goals
    ↓
Milestones
    ↓
Tasks
    ↓
Learning Sessions
    ↓
Journal
    ↓
Progress
```

Features outside this journey should not be allowed to unnecessarily delay the MVP.

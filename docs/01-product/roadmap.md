# Product Roadmap

## 1. Purpose

This roadmap describes the planned evolution of Mezgeb from its initial MVP into a more complete learning platform.

The roadmap is organized by product capability rather than implementation tasks.

The goal is to build Mezgeb incrementally while keeping the core learning experience simple and useful.

---

# 2. Product Evolution

Mezgeb will evolve through four broad stages:

1. **MVP — Core Learning Tracker**
2. **Post-MVP — Deeper Progress & Organization**
3. **Advanced — Intelligence & Personalization**
4. **Future — Ecosystem & Community**

The stages are intentionally flexible. Features may move between stages based on user feedback and implementation priorities.

---

# 3. Phase 1 — MVP

### Objective

Build the smallest complete version of Mezgeb that supports the fundamental learning loop.

> Goal → Milestones → Tasks → Study → Record → Reflect → Review Progress

### Features

#### Authentication

* User registration
* User login
* User logout
* Basic profile
* Protected application areas

#### Goals

* Create goals
* View goals
* Edit goals
* Delete/archive goals
* Goal status
* Goal progress

#### Milestones

* Create milestones
* Edit milestones
* Delete milestones
* Reorder milestones
* Complete milestones
* View milestone progress

#### Tasks

* Create tasks
* Edit tasks
* Delete tasks
* Complete tasks
* Reopen tasks
* Task status

#### Learning Sessions

* Record a learning session
* Associate session with a goal
* Optionally associate session with a milestone
* Record duration
* Record topic
* Add description/reflection
* View session history

#### Journal

* Create journal entries
* Edit entries
* Delete entries
* View entries
* Associate entries with goals/milestones
* Record dates

#### Dashboard

* Active goals
* Goal progress
* Recent activity
* Recent learning sessions
* Learning time
* Basic streak information
* Quick actions

#### Progress

* Goal completion progress
* Task completion
* Learning time
* Session history
* Basic activity history
* Basic streak

#### Core UX

* Responsive layout
* Navigation
* Loading states
* Empty states
* Error states
* Basic accessibility
* Consistent UI patterns

### MVP Success Condition

A user should be able to:

> Create a learning goal → break it into milestones → create tasks → study → record the session → complete tasks → write a reflection → review progress.

If this loop works smoothly, the MVP is fulfilling its primary purpose.

# 5. Phase 3 — Advanced Intelligence

### Objective

Use AI to help users understand their learning data rather than simply storing it.

AI features should enhance the learning experience rather than replace the user's own learning process.

### Potential Features

#### AI Journal Assistance

* Summarize journal entries
* Extract key lessons
* Identify recurring difficulties
* Suggest reflection prompts

#### AI Progress Insights

* Identify learning patterns
* Summarize progress across a goal
* Highlight areas that may need review
* Generate periodic learning summaries

#### AI Learning Assistance

* Suggest next learning steps
* Help break large goals into milestones
* Suggest tasks from a learning objective
* Generate review questions

#### AI Search

Allow users to ask questions about their own learning history.

For example:

> "What have I studied about React this month?"

or:

> "Which topics have I struggled with repeatedly?"

### Important Principle

AI should work from the user's learning data and provide assistance, not become the central purpose of Mezgeb.

# 6. Phase 4 — Future Ecosystem

### Objective

Expand Mezgeb beyond an individual learning tracker if there is a genuine need for broader functionality.

### Potential Features

#### Integrations

* GitHub
* Calendar
* Learning platforms
* Import/export
* External notes
* Productivity tools

#### Notifications

* Learning reminders
* Goal reminders
* Session reminders
* Review reminders

#### Community

Potential future capabilities could include:

* Public learning profiles
* Sharing learning journeys
* Learning communities
* Discussion around learning goals
* Following other learners

These features should only be introduced if they support the core learning experience without turning Mezgeb into a generic social or productivity platform.

#### Mobile

* Mobile web improvements
* Progressive Web App
* Native mobile application

---

# 7. Features Explicitly Deferred

The following features are intentionally not part of the initial product:

* Social networking
* Competitive leaderboards
* Complex gamification
* Full project management
* Course marketplace
* General-purpose note-taking
* Team collaboration
* AI-first workflows
* Complex calendar management
* Large-scale integrations
* Native mobile applications

These may be reconsidered later based on actual user needs.

---

# 8. Product Priorities

The roadmap follows this priority order:

### 1. Learning Structure

Help users organize what they want to learn.

### 2. Learning Activity

Help users record what they actually study.

### 3. Reflection

Help users capture what they learned and what they need to improve.

### 4. Progress

Help users understand how their learning is developing over time.

### 5. Intelligence

Use accumulated learning data to provide useful insights.

### 6. Expansion

Add integrations, community, and additional platforms only when they provide clear value.

---

# 9. Guiding Principle

Mezgeb should grow outward from its core learning loop rather than accumulating unrelated features.

> **First, help users record their learning. Then help them understand it. Finally, help them learn from it.**
